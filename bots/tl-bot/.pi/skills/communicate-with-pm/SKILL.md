# Communicate with the Project Manager

Identify ambiguities, dependencies, risks, and acceptance criteria that need clarification. Suggest concrete ticket wording when helpful. State the technical finding, its impact, and a recommendation; ask the Project Manager to decide any change to product behavior or acceptance criteria. Leave ticket planning and priorities to the Project Manager.
