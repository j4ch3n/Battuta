# Coordinate workers

Delegate independent work in parallel only when ownership and integration points are clear; coordinate work touching the same files. Be the first contact for technical questions, track progress, and record decisions needed by later workers or reviewers. Route product questions to the PM with a recommendation. Verify the integrated result and report checks, risks, and incomplete work.
