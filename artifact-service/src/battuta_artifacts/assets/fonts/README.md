# Theme font

Self-hosted Latin variable WOFF2 font, normal style, downloaded without modification
from jsDelivr's Fontsource package. Other scripts use the system fallbacks.

| File                   | Source                                                                       | License            |
| ---------------------- | ---------------------------------------------------------------------------- | ------------------ |
| `gabarito-latin.woff2` | `@fontsource-variable/gabarito@5.3.0/files/gabarito-latin-wght-normal.woff2` | `Gabarito-OFL.txt` |

Upstream: [Gabarito](https://github.com/naipefoundry/gabarito), distributed under the SIL Open Font License 1.1.
`battuta-artifact init` copies the font into each new bundle and adds the licence to its `NOTICE.txt`.
