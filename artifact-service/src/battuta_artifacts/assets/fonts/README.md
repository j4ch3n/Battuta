# Index fonts

Self-hosted Latin variable WOFF2 fonts, normal style, downloaded without modification
from jsDelivr's Fontsource packages. Other scripts use the system fallbacks.

| File                     | Source                                                                           | License              |
| ------------------------ | -------------------------------------------------------------------------------- | -------------------- |
| `newsreader-latin.woff2` | `@fontsource-variable/newsreader@5.3.0/files/newsreader-latin-wght-normal.woff2` | `Newsreader-OFL.txt` |
| `inter-latin.woff2`      | `@fontsource-variable/inter@5.3.0/files/inter-latin-wght-normal.woff2`           | `Inter-OFL.txt`      |

Upstream: [Newsreader](https://github.com/productiontype/Newsreader), [Inter](https://github.com/rsms/inter).
