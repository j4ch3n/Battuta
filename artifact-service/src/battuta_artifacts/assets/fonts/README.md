# Public Sans

Self-hosted Latin variable WOFF2, normal style, weights 100–900. Other scripts use
the system fallback. Source: Fontsource `@fontsource-variable/public-sans@5.3.0`,
`files/public-sans-latin-wght-normal.woff2`, downloaded from jsDelivr without modification.

Upstream: <https://github.com/uswds/public-sans>. Distributed under the SIL Open Font License 1.1; see `OFL.txt`.
