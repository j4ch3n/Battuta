# Slides reference

A complete HTML/CSS deck with a fixed 1920×1080 stage, letterboxing, keyboard
and button navigation, print layout, comparison, SVG plot and 3D examples.
The stage pattern is adapted from frontend-slides; no theme selection or setup
is required. These examples are starting points, not restrictions.

`deck.js` fits the stage and warns on overflow instead of shrinking the content.
Split dense slides. `plot.js` reads `data/plot.json`; `scene.js` uses the bundled
Three.js 0.160.1 module, with rotation buttons and a text alternative. It renders
only on demand. Missing example sections are safe to remove.

Use supported evidence instead of the fictional data. Keep captions and tables
consistent with plots. Check desktop/mobile letterboxing, keyboard controls,
overflow, and no-WebGL behavior. The artifacts skill owns publishing and
delivery verification; extra runtime files require explicit sharing. This guide
is not served.
