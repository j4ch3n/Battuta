Start with the decision, then explain the trade-off

This example compares two fictional compute plans. The smaller plan is a useful starting point when the working set fits in memory. The larger plan buys headroom, but that headroom has an operating cost. A real report would replace these assumptions with measured evidence.

  • Make the recommendation clear without implying certainty.
  • State the condition that would change it.
  • Keep evidence, inference and illustrative material distinct.

Break the problem into bounded questions

  1. Measure the actual working set, including peak overhead.
  2. Compare capacity and cost under the same workload.
  3. Validate the preferred plan before committing.

Capacity

The working set must fit with room for peaks. Averages alone do not establish that.

Cost

Compare the same period and utilization assumptions; a lower hourly price is not the full cost.
