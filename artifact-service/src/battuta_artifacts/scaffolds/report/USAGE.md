# Report reference

A working reading-first HTML/CSS example with prose, bullets, breakdowns, cards,
a comparison table, an SVG plot and 3D. Adapt, replace, remove or extend any part
to suit the content; these files are examples, not authoring restrictions.

`plot.js` reads `data/plot.json`; duplicate a figure to demonstrate another plot.
`scene.js` uses the bundled Three.js 0.160.1 module, renders on demand and tolerates
missing figures or unavailable WebGL. Captions and tables remain readable without
visualizations. Keep them aligned with the data. No dependency installation is needed.

The initial data is illustrative, not evidence. Replace it with supported facts,
sources, labels and uncertainty. Check narrow screens, keyboard focus and failure
states. New runtime files must be explicitly allowlisted before delivery. Use the
artifacts skill for publishing and delivery verification. This guide is not served.
