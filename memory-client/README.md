# Battuta memory client

A Pi adapter for configurable conversation capture and PM memory continuity. It durably queues scoped facts, loads the shared owner profile for PM, and provides an isolated nightly dream tool for validated consolidation, whole-profile refresh and private reflections.

See [release setup](../RELEASE.md#extension-and-skill-setup-index), [memory operations](../docs/memory-service.md), and the [PM](../shared-skills/memory/SKILL.md) / [TL](../shared-skills/memory-tl/SKILL.md) memory skills.
