# Battuta memory client

A thin Pi lifecycle adapter for periodic conversation-memory extraction and MCP upload. It durably queues work, freezes project scope per request, and loads an existing `ME.md` read-only for PM only.

See [release setup](../RELEASE.md#extension-and-skill-setup-index), [memory operations](../docs/memory-service.md), and the [memory skill](../shared-skills/memory/SKILL.md).
