# Working notes

Notes and drafts are shared local assignment files edited with Pi's built-in
tools. See [assignment runtime](assignments.md) for identity, paths, and
prompt-level freezing. The note-taking and draft-writing runtime skills own usage.

Role notebooks, local note/draft CLI commands, and current-notebook pointers are
not active workflows. Existing files, registered references, and historical
metadata remain untouched; no migration or import is performed.
