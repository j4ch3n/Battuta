# Bot setup

Python configuration tools for CoS, Manager and Worker bots, shared by source setup and released installations. Reads per-profile TOML manifests and owns file preparation, Telegram refresh, MCP connections, skill validation, and private settings defaults.

Uses its own locked uv environment. See [manifest reference](../../docs/bot-setup.md), [development commands](../../docs/commands.md), and [release setup](../../RELEASE.md) for usage.
