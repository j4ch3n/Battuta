# Visual, behavior and sharing review

Check the actual current render at narrow/desktop widths, every slide, and print
where applicable. Inspect reading order, hierarchy, overflow, labels/units, sources,
contrast, image credits and text alternatives. Do figures explain mechanisms or
merely name boxes? Does the caption state a supported takeaway?

Exercise real keyboard controls, focus return, reduced motion, pause/reset and
forward/backward replay. State, captions and badges must agree on one event model.
Inspect default/resting content, missing data, failed imports/styles/fonts and
multiple diagram mounts. An illustration must not be labeled live telemetry.
Color alone must not carry meaning; text should still explain the result without JS.

Base CSS and extension CSS should coexist without changing unrelated prose or
library-owned SVG sizing. Inspect Reveal containment and live-diagram zoom when
those capabilities are used. Source checks or mocked tests do not prove actual
browser/CDN compatibility; say what remains unverified.

Inspect the exact intended runtime allowlist and publication authority. Private
notes, credentials and unrelated sources must not be shared. A Worker declaring
completion, a local render, a published URL, Manager approval and owner acceptance
are different outcomes. Do not publish or expand sharing to obtain review evidence.

For a **blocked** verdict, name the missing evidence/access and what check would
resolve it. For **changes-required**, specify the observed defect and concrete fix.
For **ready**, identify the reviewed version and actual checks, with any limits.
