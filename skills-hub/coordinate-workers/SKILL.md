# Coordinate workers

Delegate bounded TODO items within the commissioned project assignment using the available runtime; do not create independent assignments for workers. Be the first contact for technical questions, track shared progress, and record decisions needed by later workers or reviewers. Route product questions to CoS with a recommendation. Verify the integrated result and report every delivery through Agent Mail, including checks, risks, and incomplete work. This guidance adds no worker runtime or scheduling mechanism.
