# Research

## Objective and boundaries

Answer the actual question with traceable evidence, alternatives, changed
understanding, and honest uncertainty. Work within the supplied question, inputs,
constraints and evidence boundary. This method grants no new authority.

Build an evidence-backed understanding before choosing how to present it. Scale
the investigation to the question: a narrow source check needs a direct answer,
not a research ceremony. Local-only requests stay local.

## Workflow

1. **Frame the question.** Identify the purpose, existing knowledge, constraints
   and the answer needed. Use supplied relevant context; verify
   stale facts. Let context change priorities and explanation, not decorate a
   generic report. Keep unrelated personal information private.
2. **Investigate.** Read [investigation](references/investigation.md). Start with a
   provisional frame, inspect sources, then choose distinct investigative lenses.
   Follow evidence-driven questions and counterevidence rather than filling an
   outline chosen in advance. Respect the standing evidence/tool-access rules.
3. **Organise selectively.** Keep findings with source references, dates or
   versions, supported scope and material limitations. Compare compatible units,
   populations and time periods; distinguish independent corroboration from
   copies of one source. Use only as much working structure as the question needs.
4. **Revise understanding.** Read [pre-writing](references/prewriting.md). Separate
   supplied confirmed facts, sourced findings, calculations and inference. Let
   discoveries change the question, outline and provisional answer.
5. **Stop and hand off.** Answer when evidence is sufficient for the stated purpose,
   the bounded budget is exhausted, or remaining evidence is inaccessible. State
   material gaps. Hand over the question, takeaway, mechanism, changed understanding, relevance,
   strongest alternative, uncertainties and sources—not a search transcript.

Return findings and unresolved gaps to the requester through the reporting route
supplied by the execution context. If a separate reporting or persistence action
is required, confirm it succeeded before claiming delivery. Missing essential
evidence is a limitation, not permission to invent an answer. Learning can be the
outcome; do not manufacture a recommendation or decision.

For example, compare alternatives with inspected sources and counterevidence,
then explain how the evidence changed the provisional frame. Avoid a search
transcript or recommendation unsupported by inspected sources. **Why:** learning
is useful even when it does not justify an action.
