# Agent mail

Agent mail connects the Project Manager and Tech Lead through their running Pi agents, supporting focused questions, work handoffs, progress updates, and verified results.

## Features

- Role-addressed messages and structured replies.
- Durable delivery and recovery across agent restarts.
- Response expectations and follow-up handling.
- Internal coordination alongside human-facing Telegram conversations.
